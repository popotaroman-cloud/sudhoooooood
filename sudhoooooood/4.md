# stu4 — ระบบวิชาการ วิจัย และกิจการนักศึกษา

**Modules รับผิดชอบ:** `academic` · `research` · `student`  
**BPMN Processes:** `curriculum-approval.bpmn` · `research-grant-approval.bpmn`  
**Phase:** 2 (academic) → Phase 3 (research, student)  
**FR รวม:** 21 FRs (FR-ACAD × 7, FR-RES × 7, FR-STU × 7)  
**อ้างอิง:** [fr/academic.md](fr/academic.md) · [fr/research.md](fr/research.md) · [fr/student.md](fr/student.md)  
**Dependency:** stu1 (shared-kernel, BPMN Engine) · stu2 (HR API, Facility API) · stu3 (Finance API)

---

## 1. ชื่อโครงงาน

**ระบบบริหารงานวิชาการ วิจัย และกิจการนักศึกษา**  
*(Academic Operations, Research & Student Affairs Management System)*

เป็น **output layer** ของระบบ — ผลผลิตหลักของคณะ ได้แก่ การเรียนการสอน งานวิจัย และการดูแลนักศึกษา ทำงานบนฐานข้อมูลที่ module อื่นสร้างไว้

## API Contract — Mock ที่ stu4 ต้องสร้างเอง (สัปดาห์ 1–2)

stu4 ไม่ได้กำหนด interface ใหม่ — แต่ต้องสร้าง mock ทุกตัวที่ต้องใช้จาก stu1, 2, 3

```typescript
// stu4 mock ทั้งหมดนี้ และ replace ทีละตัวตาม milestone
import type { ISharedKernelService } from 'contracts/shared.interface'
import type { IHRService }           from 'contracts/hr.interface'
import type { IFacilityService }     from 'contracts/facility.interface'
import type { IFinanceService }      from 'contracts/finance.interface'

// MockSharedKernelService → switch real @ M2 (W5)
// MockHRService           → switch real @ M3 (W6)
// MockFinanceService      → switch real @ M4 (W9)
// MockFacilityService     → switch real @ M5 (W12)
```

```typescript
// ตัวอย่าง MockFacilityService (ใช้จนถึง W12)
class MockFacilityService implements IFacilityService {
  checkRoomAvailability(roomId: string, slot: TimeSlotDTO) {
    // ห้อง ENG-301 ว่างเสมอใน mock
    return Promise.resolve(roomId !== 'BLOCKED')
  }
  getRoomById(roomId: string) {
    return Promise.resolve({ id: roomId, name: `Room ${roomId}`, capacity: 40 })
  }
}
```

> stu4 ออกแบบ **service injection pattern** ตั้งแต่ต้น เพื่อ swap mock → real โดยไม่แก้ business logic
