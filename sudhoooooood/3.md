## 1. ชื่อโครงงาน

**ระบบบริหารการเงิน จัดซื้อจัดจ้าง และแผนยุทธศาสตร์**  
*(Financial Management, Procurement & Strategic Planning System)*

## API Contract — Interface ที่ stu3 กำหนด (สัปดาห์ 1–2)

stu4 implement `MockFinanceService` จาก interface นี้ก่อนที่ stu3 จะเสร็จ

```typescript
// contracts/finance.interface.ts
export interface IFinanceService {
  getBudgetBalance(budgetLineId: string): Promise<BudgetBalanceDTO>
  checkFundAvailability(amount: number, budgetLineId: string): Promise<boolean>
}

// BudgetBalanceDTO
// { budgetLineId, allocated, committed, actual, available }
```

```typescript
// stu4 สร้าง mock นี้ใช้เองก่อน M4
class MockFinanceService implements IFinanceService {
  getBudgetBalance(budgetLineId: string) {
    return Promise.resolve({
      budgetLineId,
      allocated: 500000,
      committed: 120000,
      actual: 80000,
      available: 300000,
    })
  }
  checkFundAvailability(amount: number, budgetLineId: string) {
    return Promise.resolve(amount <= 300000)
  }
}
```

// interfaces ที่ stu3 ต้อง mock ก่อนได้รับจาก stu1 และ stu2

// MockHRService          — mock ตาม contracts/hr.interface.ts (payroll info)
