# stu2 — ระบบบริหารบุคลากร สิ่งอำนวยความสะดวก และสารบรรณ

**Modules รับผิดชอบ:** `hr` · `facility` · `document`  
**BPMN Processes:** `leave-request.bpmn` · `staff-onboarding.bpmn`  
**Phase:** 1 (hr, document) → Phase 3 (facility)

**อ้างอิง:** [fr/hr.md](fr/hr.md) · [fr/facility.md](fr/facility.md) · [fr/document.md](fr/document.md)  
**Dependency:** stu1 (shared-kernel API, JWT, BPMN Engine)

## 1. ชื่อโครงงาน

**ระบบบริหารบุคลากร ทรัพยากรกายภาพ และการจัดการเอกสารราชการ**  
*(Human Resource, Facility & Document Management System)*

เป็น **core domain** ที่ module อื่นอ้างอิงข้อมูลบุคลากรบ่อยที่สุด hr module จึงต้องเสร็จก่อน stu3 และ stu4

## 3. เปรียบเทียบซอฟต์แวร์ที่มีอยู่

| ซอฟต์แวร์ | ลักษณะ | ข้อดี | ข้อจำกัด | เหตุผลที่ไม่เลือก |

| **พัฒนาเอง** (เลือก) | Custom, modular | ตรงตาม workflow ไทย, integrate ระบบอื่นได้ | ต้องใช้เวลาพัฒนา | — |
| SAP HCM | Enterprise ERP | ครบครัน | ราคาสูงมาก, customize ยาก | งบไม่พอ |
| Oracle HCM Cloud | SaaS ERP | managed | vendor lock, ค่าใช้จ่ายสูง | vendor lock |
| BambooHR | SaaS HR | UI ดี | ไม่รองรับ workflow ราชการไทย | ไม่ตรง context |
| ระบบ DPIS (กรมบัญชีกลาง) | ภาครัฐไทย | สำหรับข้าราชการ | ไม่ครอบคลุมพนักงานมหาวิทยาลัย | scope ไม่ตรง |

### 3.2 Facility Management

## API Contract — Interface ที่ stu2 กำหนด (สัปดาห์ 1–2)

stu3 และ stu4 implement Mock จาก interface นี้ก่อนที่ stu2 จะเสร็จ

```typescript
// contracts/hr.interface.ts
export interface IHRService {
  getEmployeeById(id: string): Promise<EmployeeDTO>
  getEmployeePayrollInfo(id: string): Promise<PayrollInfoDTO>
  getFacultyByDepartment(deptId: string): Promise<FacultyDTO[]>
}

// contracts/facility.interface.ts
export interface IFacilityService {
  checkRoomAvailability(roomId: string, slot: TimeSlotDTO): Promise<boolean>
  getRoomById(roomId: string): Promise<RoomDTO>
}
```

```typescript
// stu3 + stu4 สร้าง mock นี้ใช้เองก่อน M3
class MockHRService implements IHRService {
  getEmployeeById(id: string) {
    return Promise.resolve({ id, name: 'Test Employee', departmentId: 'CS' })
  }
  getEmployeePayrollInfo(id: string) {
    return Promise.resolve({ id, baseSalary: 30000, positionAllowance: 5000 })
  }
  getFacultyByDepartment(deptId: string) {
    return Promise.resolve([{ id: 'f1', name: 'Dr. Test', status: 'active' }])
  }
}
```
